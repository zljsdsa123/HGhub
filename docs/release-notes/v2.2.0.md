## HGhubX 2.2.0

架构重构 + Android TV / 车机老内核兼容 + 开屏与播放体验全面升级的正式版本。包含 pre.1 / pre.2 及后续全仓审计与性能打磨的全部内容。

### 新增

- **Android TV 独立版**（`com.hghubx.tv`）：Leanback 桌面入口与横屏 Banner、遥控器方向键 / 确认 / 返回 / 媒体键导航、本地 IndexedDB 片库与拼音/标题搜索索引、overscan 安全边距设置。
- **老 WebView 与车机大屏兼容**（#138）：前端构建降级至 `chrome66 / safari14.1`（含 CSS `dvh / color-mix / cascade-layers` 回退、经典 `iife` Worker、ES5 启动看门狗与运行时 API 垫片）；Android 标准版原生层桥接系统状态栏与车机常驻底栏安全区（`--native-sat/sab/sal/sar`），`quick` 与正式构建均覆盖 32 位 `arm` 与 64 位 `arm64`。
- **长按加速可换挡**（#146）：右上长按 2x 起，按住左右滑每 80px 换一档（2x → 3x → 4x → 6x，来回滑可升可降，每档震动反馈）；上滑后松手锁定当前档位。
- 设置 → 播放新增「全屏无操作自动隐藏控件」：关 / 3秒 / 5秒 / 10秒（默认 3 秒，暂停时不隐藏）（#146）。
- 长按操作提示加入「双击暂停播放」说明。

### 改进

- **开屏零闪烁与冷启动大幅提速**：
  - 原生窗口、`index.html` `data-hg-launching` 背景锁与开屏层统一锚定 `#071218`，彻底消除亮色/暗色主题切换时的首尾白屏或灰屏闪烁，以及 `<Suspense>` 未就绪时的空帧跳变；
  - 开屏动画改为全外层独立 GPU 合成层（仅驱动 `transform3d` + `opacity`），消除逐帧 SVG 路径重绘与多段缓动顿挫，首帧独占上屏后下一帧并发挂载业务壳；
  - 消除入口二次动态分包瀑布流，并将 `Feed` + `hls.js`（`524 kB`）从首屏壳剥离并行预热，`AcceptedApp` 关键路径体积缩减 **84.6%**（降至 `113.8 kB`），首屏选线与推荐流请求显著提前。
- **前端渲染与状态隔离**：Toast 通知与账号同步状态改为独立订阅，避免全局重渲染；内联播放器全屏与分页请求逻辑收口复用；亮色模式表面层次与对比度优化。
- 加速提示弱化并入顶部倍速胶囊（「上滑后松手锁定 / 松手锁定」），移除画面中部拖放提示；全屏右上「退出 / 锁定」两键 44×44、间距 12px（#146）；大屏横屏操作栏自动切换双列紧凑布局避免顶边裁切（#138）。
- **全站界面视觉对齐与内容屏蔽补全**：修复分类页「排行榜 / 专题 / 标签」窄屏高度偏大与上偏错位并补齐专属语义图标，统一全站二级页顶栏尺寸与边距、标签分组卡片与单行屏蔽工具条、搜索页三段式卡片间距、海报双徽章等高防撞、桌面侧栏图标中轴及设置展开面板双重内边距问题；搜索页「热搜榜」与「热门题材」同步接入屏蔽标签过滤；移除视频与帖子详情的分享入口并重排操作栏对齐；清理冗余副标题，「HGhubX 热榜」统一为「排行榜」。
- 仓库结构整理：前端按 `app / features / shared` 归组并拆分 `Feed` 子面板与手势模块；Rust 按 `api / net / media / lines` 拆分并独立 `updater / net_diag / publish_parser`。

### 修复

- **切换线路不再掉登录，且在播流不中断转圈**（#145）：
  - 固定线路与发布页确认镜像之间手动/自动切线及冷启动重启均保留登录会话（即使当前回退到固定线路也会校验已存镜像信任）；自定义线路仍严格清空凭据，移除 `.ai` 导航站；
  - 区分代理变更与线路变更事件：后台自动选线后健康在播视频保持连贯播放，仅对未就绪/报错/预取项按新线路重拉。
- **播放与多实例交互修复**：
  - 修复移动端底部信息浮层遮挡右侧「全屏」按钮命中区域，并补齐旧版 WebKit 前缀 Fullscreen API、桌面窗口全屏回退及 Linux WebKitGTK 窗口全屏状态同步；
  - 暂停状态下进入/退出全屏或拖动进度条均保留用户暂停意图，不再意外恢复播放（#138）；
  - 修复压栈多级 `Feed` 页面同时响应全屏快捷键或画中画状态串扰、音量滑块松手跳变、锁屏态残留手势、搜索返回焦点与我的/关注列表状态同步细节；
  - 竖屏视频按原始比例完整显示，横屏保留「铺满 / 适应」切换（#142）。
- **后端安全与缓存隔离加固**：媒体分片与图片缓存纳入代理/安全模式代次隔离，严格校验本机 loopback Host/Origin 边界，更新检查精确匹配当前平台安装包后缀，安卓剪贴板诊断日志裁剪至 256KiB 上限（#142）。
- 启动动画期间按返回键仅跳过开屏，不再误触发底层页面弹栈或直接退出应用。
- TV：「继续观看」封面与货架等宽；选集每格固定高度、长标题两行截断；跨包迁移后端未移植时正常启动。

### 验证

- 全部 CI/CD 合并为单一工作流，并复用预装工具链与包缓存加速：Rust 112 通过 / 0 失败，浏览器 smoke 全通过，前端双版本（标准版 + TV 版）构建、文档链接、尺寸预算与播放回归矩阵全绿通过。

### 已知限制

- TV↔手机标准包之间的账号/片库跨包迁移后端尚未移植，TV 端迁移入口保持隐藏。
- iOS 包为无证书构建（需自行签名侧载）；macOS 为 ad-hoc 签名。
