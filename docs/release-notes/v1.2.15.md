## 1.2.15

### 变更
- 专题列表与专题详情改为一次取全（此前接口默认每页仅回 9 个专题、20 部视频，会漏内容）。
- 搜索页新增「热搜榜」（接口实时数据）。
- 分类页新增「黄果吃瓜」入口：吃瓜分类（热门吃瓜 / AI原创）、图文详情、相关推荐。
- 新增关注流（我的关注）与用户主页（资料、作品、关注）。
- 播放页详情抽屉新增作者卡片（可跳用户主页）、相关推荐横滑。

### 优化
- 底栏改为液态玻璃（半透明 + 磨砂 + 顶部高光），Android 与 iOS 通用。
- iOS 底部留白修复：改用 100dvh 动态视口，移除启动时 html 高度锁死逻辑。
- iOS 横屏适配对齐 LNPANDY 增强版设计：原生旋转自动进入/退出全屏、screen.orientation 锁定、全屏与旋转后滚动位置校准（修复「横屏播放变成别的剧集」）。
- 瀑布流改 CSS Grid，规避 WebKitGTK 2.52.6 下多列首卡被裁剪的问题（搜索/分类/专题详情共用）。

### 构建产物
- Android：arm64 / arm / x86_64 分 ABI 分包
- iOS：未签名 ipa（需自行签名）
- Windows：安装包 + 便携版

- Linux：amd64 deb
