## HGhubX 2.1.1

### 更新点

- **线路选择**：合并重复的“推荐镜像”和“镜像线路”区域为一个镜像列表，当前线路置顶；保留刷新和连通性检测。
- **启动体验**：统一各平台启动背景，减少启动首帧闪烁。
- **搜索**：热门题材使用真实标签数据，并可直接打开对应片单。

### 修复点

- 修复播放恢复、代理切换后的恢复队列及媒体分片缓存隔离问题。
- 修复专题分页、收藏同步空状态和搜索框焦点处理。
- 补齐 iOS 原生媒体传输的 Range 响应，改善视频探测与播放兼容性。
- 修复帖子详情热度和清理观看历史前的确认交互。

### 构建产物

- Linux amd64：`.deb`
- Android：arm64、arm、x86_64 分 ABI APK
- Windows：x64 安装包和便携版 ZIP
- macOS：Universal `.dmg`
- iOS：未签名 `.ipa`
