## HGhubX 2.2.0-pre.1（预发布）

预发布版本，包含结构整理与一轮体验改进，欢迎试用反馈；不作为正式版本推送。

### 新增

- **Android TV 版**并入全量构建：独立安装包（com.hghubx.tv），Leanback 桌面入口、
  横屏显示、遥控器方向键/确认/返回导航、TV banner 与 overscan 安全边距设置。
- 移动端长按操作提示新增「双击暂停播放」说明（手势本身早已支持）。

### 改进

- **冷启动更快**：已同意协议的用户在启动动画期间就开始选线、加载首屏并请求播放，
  动画结束时内容已就绪；首次使用的协议流程不变，默认静音不变。
- 自动选线默认开启（核实原有行为即如此，未改动）。
- 界面文案清理：设置页分组副标题、「清理缓存」行内说明等复述式文字移除
  （清理范围说明保留在确认弹窗里）；「HGhubX 热榜」改名「排行榜」。
- 播放页移除重复的「不感兴趣」按钮，统一为长按视频打开偏好菜单。

### 修复

- 竖屏视频在手机上不再被裁切铺满，按原始比例完整显示；横屏视频的
  「铺满 / 适应」切换保留（#142）。
- 安卓播放诊断日志复制失败：导出裁剪到 256KiB（保留环境信息与最近事件），
  不再超出系统剪贴板单次事务上限（#142）。
- 启动动画期间按返回键不再误触发页面导航或退出应用。
- TV 版在跨包迁移后端未移植时也能正常启动进入主界面。

### 已知限制

- TV↔手机标准包之间的账号/片库跨包迁移后端尚未移植，TV 端迁移入口保持隐藏。
- iOS 包为无证书构建（需自行签名侧载）；macOS 为 ad-hoc 签名。
