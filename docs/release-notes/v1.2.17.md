## 1.2.17

### 修复
- **iOS 长按快进唤起放大镜（#18）**：1.2.16 的 CSS 方案（`-webkit-user-select:none`）挡不住 iOS 15+ 的 WKWebView 原生文本选择放大镜（loupe）。改为原生关闭：页面加载后默认 `WKPreferences.isTextInteractionEnabled = false`，同时关掉 `allowsLinkPreview`；输入框获得焦点时前端自动重新打开、失焦再关闭，搜索 / 评论 / 登录等文本输入不受影响。
- **竖版切集胶囊遮挡画面（#19）**：从画面正中移到右边缘、只留图标与状态点（去掉「切集」两字），显示 / 隐藏带淡入淡出过渡；横版视频保持原来的居中横排不变。
- **搜索页自动弹键盘（#20）**：移动端进入搜索页不再自动聚焦搜索框（原来 iOS 会立刻弹出键盘遮住内容），桌面端仍自动聚焦。

### 新增
- **全屏自动净屏**：移动端全屏 3 秒无操作自动隐藏全部控件，单击画面立即切换显隐，暂停时保持显示；竖版切集胶囊锚定操作栏上方，不再与收藏按钮重叠。
- **播放页画质徽章（#12）**：该集存在 HEVC 高清源时，标题旁显示当前画质徽章（HD 高清 / 标清），点按一键切换，无需进设置。
- **侧边控件风格统一**：上下划切集开关从悬浮胶囊移入右侧操作栏，与收藏 / 评论 / 全屏 / 分享同列（图标 + 文字竖排，开启时金色高亮）；HD / 标清画质徽章同样并入操作栏同风格显示，点按切换不变。
- **全屏下集按钮**：全屏态底部控件条新增「下集」按钮（有下一集才显示）。此前全屏下切集只能靠上下划手势，关掉手势就完全没法切。
- **网络诊断升级**：DNS 探测改走与真实请求相同的解析路径（修复「诊断报 DNS 失败、实际却打得开」的假阴性），新增 TCP 连通性探测；诊断结果自动给出结论码与排查建议（fake-ip / DNS 失败 / TCP 阻断 / TLS 异常等 11 种），复制出来是分段可读报告，直接贴 issue 即可定位。

### 变更
- **播放页去黑边**：移除底部压暗渐变与整体压暗层（原来进度条周围一圈黑），标题与详情标签降透明度，进度条透明化、仅保留白色进度点标示播放位置。
