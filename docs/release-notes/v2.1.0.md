## HGhubX 2.1.0

HGhubX 2.1 新增标签屏蔽，完善账号同步，并优化播放和加载体验。

### 更新点

- **内容偏好**：新增按标签屏蔽，可在设置或视频“不感兴趣”中添加规则；首页自动跳过命中内容，列表支持临时展开，收藏和历史保留记录。
- **播放手势**：手机端支持左下长按减速、右上长按加速，中心小方块长按“不感兴趣”；首次进入播放器显示区域提示，视频详情支持点击标签跳转。
- **启动体验**：新增开屏动画和首次使用协议。
- **性能**：优化页面按需加载、下一条视频和下一集预取，精简无效代码与重复请求。
- **界面**：更新了 UI，自己体验。

### 修复点

- 修复游客模式保存观看进度、收藏等数据时回滚设置的问题，包括自动恢复静音，以及音量、启动静音、优先高清、滑动切集和搜索历史被旧快照覆盖。
- 修复评论区出现 HTML 标签和脚本片段、长评论和长昵称换行异常的问题；手机播放页面显示评论数量，评论面板读取当前剧集的数量。
- 修复首页刷视频后进入全屏跳到其他视频的问题。
- 修复手机端吃瓜视频控制按钮隐藏的问题，调整小屏控制栏，并补充全屏失败时的屏幕内全屏模式。
- 修复收藏和观看历史只显示首批内容、账号数据未完整回填的问题，完善关注列表分页和失败重试。
- 修复账号、线路切换后的迟到请求污染当前数据，以及互动操作失败仍显示成功的问题。
- 修复详情封面加载状态异常，优先加载详情封面，并合并同地址的下载和解密请求。
- 补齐原生播放器的单段 Range 响应，返回正确的 `206`、`416` 和 `Content-Range`，改善 iOS 媒体探测流程。

- Android：arm64、arm、x86_64 分 ABI APK
- Windows：x64 安装包和便携版 ZIP
- macOS：Universal `.dmg`
- iOS：未签名 `.ipa`
