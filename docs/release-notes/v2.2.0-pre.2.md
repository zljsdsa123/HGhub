## HGhubX 2.2.0-pre.2（预发布）

在 pre.1 基础上修复三组反馈：切线掉登录（#145）、播放器手势与全屏控件（#146）、
TV 货架排版。欢迎试用反馈；不作为正式版本推送。

### 新增

- **长按加速可换挡**：右上长按 2x 起，按住左右滑每 80px 换一档（2x → 3x → 4x → 6x，
  来回滑可升可降，每档震动反馈）；上滑后松手锁定当前档位，不再固定 2x（#146）。
- 设置 → 播放新增「全屏无操作自动隐藏控件」：关 / 3秒 / 5秒 / 10秒（默认 3 秒，
  暂停时不隐藏）（#146）。

### 改进

- 加速提示弱化：去掉高亮底色，改半透明黑底白字；锁定提示并入顶部倍速胶囊
  （「上滑后松手锁定 / 松手锁定」），移除画面中部误导性的拖放目标提示（#146）。
- 全屏右上角「退出全屏 / 锁定控制」两键显式 44×44 并留出 12px 间距，不再贴死（#146）。
- 专题列表卡片去掉可选简介，封面 + 数量 + 单行标题统一高度对齐；
  专题详情页的可展开简介保留。

### 修复

- **切换线路不再掉登录**（#145）：固定线路与发布页确认的镜像之间手动/自动切线、
  重启后均保留会话（实测同账号库跨线可用）；自定义线路仍会清空会话，token 不外带。
  `.ai` 只是导航站（接口全 404），已从线路列表移除。
- **横屏全屏左右滑可以调进度了**（#146）：旋转舞台的手势坐标统一换算
  （进度拖动 / 上下划切集 / 长按换挡与锁定），全屏时不再被原生滚动取消手势。
- **全屏控件不再一碰就闪、单击稳定显隐**（#146）：移除 2.8s 不分平台的自动隐藏
  与单击语义的冲突，移动端按上面的新设置计时。
- TV：「继续观看」封面与货架等宽对齐；选集每格固定高度，长标题两行截断不再参差。

### 验证

- CI 全绿：Rust 109 通过 / 0 失败，浏览器 smoke 4/4，构建与尺寸预算通过。
- 播放回归 10/10（含 TV 遥控验收 13/13、竖屏适配、恢复与代理切换）。
- 真机手势手感与 TV 实机显示请以安装包实测为准。

### 已知限制

- TV↔手机标准包之间的账号/片库跨包迁移后端尚未移植，TV 端迁移入口保持隐藏。
- iOS 包为无证书构建（需自行签名侧载）；macOS 为 ad-hoc 签名。
