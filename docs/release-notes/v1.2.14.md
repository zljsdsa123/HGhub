## 1.2.14

### 变更
- 更新流程改为「打开下载页」：检测到新版本后，点「前往下载」用系统浏览器打开 GitHub Releases，由浏览器与系统完成下载与安装。此前应用内自行下载安装包再调起安装器的方式已移除。
- 打开失败时自动把下载地址复制到剪贴板，便于在浏览器粘贴。

### 优化
- 重写视频页快捷胶囊：多个操作合并进一个玻璃拟态胶囊组，用细分隔线对齐，标签精简为二字（切集 / 铺满 / 适应 / 横屏），视觉更统一。

### 修正
- 关于页的仓库地址改为本仓库（zxsos/HGhub），点击直接用浏览器打开。
- README 中的官方仓库与下载渠道链接同步更正。

### 构建产物
- Android：arm64 / arm / x86_64 分 ABI 分包
- iOS：未签名 ipa（需自行签名）
- Windows：安装包 + 便携版
- macOS：universal dmg
- Linux：amd64 deb

所有提交与标签均已通过 GPG 签名验证。
